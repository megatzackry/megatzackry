### About

I build systems that take over repetitive work: bots, pipelines and platforms designed around the people who actually use them.

Most of what I have shipped comes down to the same idea. Software should not be another layer between people, dressed up as connection. It should absorb the parts that were never a relationship to begin with, like the moderation queue, the spam filter, the verification email and the reminder that fires on schedule, so the hours that quietly disappear from a day go somewhere better.

### What I work on

**Automation and integration.** Turning manual, repeating processes into pipelines that run without a person in the loop. Webhooks, scheduled jobs, approval flows, notification routing, and data sync between systems that were never designed to talk to each other.

**Full stack engineering.** Front end through to infrastructure, shipped and maintained solo when it has to be. Typed forms, scheduling, authentication, transactional email, deployment, and the domain it all sits on.

**Applied AI with guardrails.** The boundary where model output has to be trusted enough to publish: prompt constraints, strict output formats, edge case evaluation, and the detection layers that catch what the model gets wrong before a user sees it.

### Selected work

**Community Automation and Moderation Platform** · [t.me/utmconfession](https://t.me/utmconfession)
A final year project that grew into a semi-anonymous community platform for 12,000+ subscribers on a modular Google Apps Script architecture. Real time moderation that redacts personally identifiable information, filters profanity and screens URLs before publication. Conversational AI assistant held to strict output formats by prompt constraints. Identity verification through university email OTP, balancing anonymity against accountability. Over 2,000 Telegram Stars generated through an automated marketplace.

**Quantum Inspired Agentic Test Case Prioritisation** · MPhil thesis, in progress
A data independent framework for deciding what to run first in regression testing when there is no execution history to learn from. LLMs perform semantic analysis of code changes to extract fault risk and complexity features, then a classical quantum inspired depolarising channel model ranks the tests, sidestepping the cost of metaheuristic search such as PSO. Runs on a GitHub Actions and Apps Script pipeline that pulls diffs by webhook and triggers Python evaluation scripts.

**End to End Booking Platform**
A customer facing booking site built and operated solo, from Zod validated forms and calendar scheduling down to the self hosted SMTP server that sends the confirmations. React with TanStack Start and Tailwind, deployed on Cloudflare Pages and Workers.

**Power Platform automation at KPMG PLT** · Sep 2023 to Feb 2024
Smart Locker Power App that notifies IT staff the moment an item is dropped off. Cloud automation that generates personalised reminder emails from pending action data instead of sending them one by one. Maintained the firm's Expense Claim System in C# and SQL Server with an AI Builder document extraction pipeline running at roughly 94 percent accuracy, and rebuilt the staff directory sync in PowerShell.
